# 交互模块演示

入口：Hub 向左滑到第二个应用页，选择 `Interaction`。PCB 底图使用用户提供的 480×480 图片，底部上滑或系统返回键退出应用。复用系统 Shell 的底部返回手势，不显示顶部标题栏。

界面在生成时整体逆时针旋转 90°，包含底图、文字、覆盖层和点击区域。运行时不修改屏幕方向；动态文字切换预先旋转的图片资源。

- 点击 LED 0–3 切换彩灯，点击 LED 4（右）、LED 5（左）切换键盘背光。
- 机械键与 PIR 的局部高亮来自实时输入。按键沿用参考示例的 Touch 采样，因此手指触摸焊盘也会触发。
- 左右 Touch 或机械键触发时，LED 5、LED 4 背光分别变为与屏幕覆盖层相同的亮绿色（`#4CFF85`）；释放后恢复触发前的颜色与开关状态。按住期间忽略该背光的界面切换，屏幕灯光同步实际成功写入的状态。
- 点击左下 IR 发射一帧 38 kHz NEC，地址 `0x00`、命令 `0x10`。提示成功仅表示本地发送完成。
- 光敏按 S31 的标称单端原始码归一化：左槽 ADC2 CH3 使用约 2196→4393，右槽 ADC1 CH4 使用约 2196→0，修正偏置和方向。端点来自当前 IDF 的 ADC 测试，不是电压校准；显示为相对百分比，不是 lux。驱动保留 Q8 小数精度进行平滑，最后才取整，避免整数百分比滤波吞掉小幅变化。首次采样及读取失败后的首次成功采样直接初始化滤波，并记录原始值。
- 中间 `AUTO >` 按钮循环选择自动、左插槽、右插槽。自动模式优先选择空闲的左侧交互板。
- 模块必须具有有效 EEPROM，类型为 `0x15`。已被其他应用占用的模块不会重复打开。

硬件任务每 50 ms 采样，UI 仅刷新变化的快照。退出时停止任务并释放 Touch、ADC、RMT 和插槽。占用期间每 500 ms 探测 EEPROM，连续两次失败后关闭；相机占用左槽期间暂停该探测以避免地址线冲突。

新 PCB 按图中丝印使用六灯串联顺序 `0,1,2,3,4,5`。旧示例为七灯硬件，其按键背光索引为 `5,6`；旧板不能直接使用此位置映射。实板逐灯对应关系仍需以实际观察核对。

场景资源由 `scene/gen_scene.py` 和 `scene/regenerate.sh` 生成，修改底图后构建会自动重新打包。桌面后端仅提供界面预览，不伪造传感器数据。
